# Certification Guide

## Levels

1. **Corpus integrity** — record counts, hashes, schemas, catalogs, and paths pass.
2. **Structural source conformance** — headers, modules, policies, delimiters, and required declarations pass.
3. **Compiler conformance** — a declared native compiler reproduces expected stages and diagnostics.
4. **Runtime conformance** — a declared runtime reproduces deterministic scheduling, branch, portal, checkpoint, and replay receipts.
5. **Release certification** — implementation, corpus, tests, manifests, signatures, and qualification statements are bound into one auditable release.

The included release demonstrates levels 1 and selected structural checks for level 2. It does not claim native compiler or runtime certification.
