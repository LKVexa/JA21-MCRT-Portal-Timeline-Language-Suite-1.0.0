# Instructor Guide

## Teaching posture

Treat the corpus as an evidence model, not a substitute for a native compiler. Require students to separate source facts, modeled expectations, structural validation, and observed runtime results.

## Assessment

- 20% source and grammar literacy
- 20% temporal and synchronization semantics
- 15% diagnostics and negative-case design
- 15% AST, R12, and MCRT traceability
- 15% deterministic replay and recovery
- 15% capstone publication and validation

## Review roles

SOPHIA leads semantic and contradiction analysis. CHARLOTTE leads reconstruction and traceability. LANDON leads implementation and deterministic tooling. Professor leads explanation and assessment. Podium leads publication quality and release evidence.

## Certification boundary

A passing course artifact is not automatically a certified native implementation. Certification requires a declared implementation profile, native test evidence, reproducible hashes, and a signed release receipt.
