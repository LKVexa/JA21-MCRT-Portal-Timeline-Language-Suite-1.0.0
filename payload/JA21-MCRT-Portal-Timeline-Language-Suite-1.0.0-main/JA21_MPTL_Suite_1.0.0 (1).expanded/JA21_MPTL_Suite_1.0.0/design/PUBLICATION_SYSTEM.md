# Publication System — Temporal Observatory

## Visual language

- Obsidian surfaces represent authoritative source and runtime state.
- Teal paths represent rational time, tracks, bindings, and deterministic execution.
- Violet rings represent portals, branching, projection, and R12/MCRT coupling.
- Gold nodes represent checkpoints, hashes, certification, and stable receipts.
- Red is reserved for contradictions, deadlocks, unresolved references, and replay drift.

## Document pattern

Every major publication begins with identity and qualification, then moves through architecture, source examples, evidence, laboratories, validation, and release references. Tables favor compact paths and stable identifiers. Code blocks preserve canonical source exactly.

## Air-gap posture

The suite uses Markdown, JSON, JSONL, CSV, EBNF, Python standard-library tools, and a local SVG cover. It contains no remote fonts, scripts, images, telemetry, or required network resources.
