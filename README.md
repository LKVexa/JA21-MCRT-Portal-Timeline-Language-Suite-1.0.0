# JA21-MCRT-Portal-Timeline-Language-Suite-1.0.0

Study causal events, virtual time, checkpoints, and replay with the JA21 MCRT Portal Timeline suite. Explore 10,000 normalized records, 1,000 source-faithful examples, a 22-chapter textbook, and offline validation tools. Designed for language researchers, educators, and implementers, with modeled results clearly distinguished from native execution.

The JA21 MCRT Portal Timeline Language Suite is a research and teaching collection for describing causal events, virtual time, checkpoints, synchronization, and replay. It gives language designers, educators, and implementation teams a structured way to examine how timeline descriptions connect to event ledgers and evidence contracts.

The package includes a 10,000-record normalized technical corpus, 1,000 source-faithful .mcrt examples, and a 22-chapter technical textbook. A twelve-week curriculum, workbook, and instructor guide support classroom use, while catalogs and architecture maps help readers navigate 45 topics across six tiers. Grammar assets, semantic operators, compiler and runtime contracts, conformance guidance, manifests, and offline validators make the material useful for retrieval, corpus analysis, and planning a future toolchain.

The October 2026 audit preserves source provenance and qualifies modeled results. The supplied package does not include a native MCRT compiler or runtime, and parts of its grammar remain incomplete. Its records describe expected behavior; observed execution receipts, a complete parser, and runtime conformance are still needed to establish operational behavior.

## Corpora and audit records

The supplied corpus layout is preserved under `payload/`. The `audit/` directory and [AUDIT_AND_UPGRADES.md](AUDIT_AND_UPGRADES.md) record source coverage, release changes, and evidence boundaries.

Historical source archives and source manifests remain provenance records. Current publication file hashes are listed in `PUBLICATION_SHA256.json`; licensing changes are recorded in `PUBLICATION_LICENSE_LEDGER.json`.
